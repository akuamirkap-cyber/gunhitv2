# Perfect Shot v2

Game arkade tembak target buah presisi berbasis React + Vite + TypeScript.

## Fitur Utama:
- **Pistol Classic**: Menggunakan art & animasi pistol klasik dengan kontrol ketuk atau tombol Spasi.
- **Quest Level 1**: Target berputar dengan rintangan dan combo hit akurat.
- **Menu Lengkap**: Menu asli dengan akses ke Gun, Ranks, Ready (Achievement), dan Setting.
- **Audio & Efek**: Suara tembakan dan efek visual terintegrasi secara lokal.
- **Penyimpanan Lokal**: Rekor skor tersimpan otomatis di perangkat.

## Cara Menjalankan:
```bash
npm install
npm run dev      # Membuka di http://0.0.0.0:3000
npm run build    # Build produksi web ke dist/
npm run lint     # Pengecekan tipe TypeScript (tsc --noEmit)
```

## Unduhan Offline:
Tersedia file offline siap pakai di folder `public/`:
- `perfect-shot-v2.zip`: Paket arsip source code dan build siap pakai.
- `perfect-shot-v2.html`: Satu file HTML mandiri yang dapat langsung dimainkan di browser tanpa koneksi internet atau server.
